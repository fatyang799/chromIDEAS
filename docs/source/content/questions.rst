(A) Questions about installation
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

(1) Conda Installation Stalls on GenomeInfoDbData Package

During the installation of chromIDEAS via conda, the process frequently stalls while attempting to download the GenomeInfoDbData dependency. This is typically caused by unstable network connections or limited bandwidth during the package retrieval step.

[Click here for detailed solution →] :doc:`questions/Installation_GenomeInfoDbData`


(B) Questions about functional clustering of chromatin states
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

(1) Manual Adjustment of Chromatin State Functional Clustering

Users may incorporate prior biological knowledge to manually refine chromIDEAS's unsupervised clustering results, either by subdividing clusters post-analysis or excluding predefined states pre-analysis, allowing for biologically-informed resolution of chromatin state classifications.
